Configurar el enlace de gestión

Después de publicar el nuevo proyecto Apps Script de gestión, pega su URL de implementación terminada en /exec. El enlace del equipo se genera a partir de ella.

Puedes reemplazar el enlace preconfigurado en este navegador; no se guardan contraseñas. No uses la URL del estudio anterior.
